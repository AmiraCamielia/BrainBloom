BrainBloom

Description
BrainBloom is a web-based platform designed to assist users in managing and improving cognitive health. The site provides a clean, user-friendly interface for tracking brain-training progress and engaging with wellness resources to foster mental growth and well-being.

Features Included
User Authentication: A secure login system to protect personal progress data.

Dashboard View: A clean interface to navigate through various cognitive exercises and resources.
Progress Tracking: Ability to view and monitor personal growth metrics.
Responsive Design: Fully optimized for both desktop and mobile viewing.
